## Status legend

| Status | Meaning |
|---|---|
| **Not assessed** | No diagnostic or assessment data exists yet for this topic. |
| **Significant gap** | Assessed; core understanding is missing or a majority of questions are answered incorrectly. |
| **Developing** | Partial understanding; inconsistent application, common errors still recurring. |
| **Mostly secure** | Generally correct with occasional slips; minor gaps under exam conditions or with harder command words. |
| **Secure** | Consistently correct across question types at the expected grade level. |
| **Mastered** | Secure performance sustained across multiple sittings, including under timed conditions. |
| **Needs delayed-retention check** | Previously Secure or Mastered, but enough time has passed since last practice that a spaced-retrieval check is due before that status can be re-confirmed. |
