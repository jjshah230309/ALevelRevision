## Part 1 — Qualification boundaries (restated as a standing check)

- Biology: AQA 7402 only.
- Chemistry: AQA 7405 only.
- Physics: AQA 7408 only; optional content restricted to **Astrophysics (§3.9)**. Medical physics, Engineering physics, Turning points in physics, and Electronics are excluded from every batch.
- Mathematics: Pearson Edexcel UK A-level Mathematics **9MA0** only. Not International Advanced Level. Not Further Mathematics.
- AS-only assessment arrangements (different paper structures, e.g. AS Biology 7401's two 90-mark papers) are never mixed into the A-level audit — every table above reports the **A-level** structure only, with AS figures shown solely for contrast where AQA's own document places them side by side.

## Part 2 — Permanent objective identifier system

**Format:**
- Biology: `BIO-[official section]-[number]` — e.g. `BIO-3.1.1-001`
- Chemistry: `CHEM-[official section]-[number]` — e.g. `CHEM-3.1.1-001`
- Physics (core): `PHYS-[official section]-[number]` — e.g. `PHYS-3.1.2-001`
- Physics (Astrophysics option): `PHYS-ASTRO-[official subsection]-[number]` — e.g. `PHYS-ASTRO-001` (or `PHYS-ASTRO-[subsection]-[number]` once §3.9's own sub-numbering is confirmed in Batch 4)
- Mathematics: `MATH-PURE-[topic]-[number]`, `MATH-STAT-[topic]-[number]`, `MATH-MECH-[topic]-[number]` — e.g. `MATH-PURE-CALCULUS-014`

**Rules in force from this batch onward:**
1. Every identifier is unique and permanent — once issued, an ID is never reassigned or reused, even if a later re-read of the specification suggests a different grouping would have been cleaner.
2. Every diagnostic question, flashcard, revision-sheet entry, exam question, mistake-log entry, and mastery-tracker row created in any later stage must cite at least one identifier.
3. Where one specification sentence bundles several independently assessable skills (e.g. "explain the effect of enzyme concentration, substrate concentration, competitive and non-competitive inhibitor concentration, pH and temperature" — five distinct explanations), it is split into separate IDs. Every such split is labelled **"Instructional subdivision of official requirement"** in the Status field of the database (Part 3, field B) — it is never presented as separate official specification wording, and the original combined statement is still quoted in full in the detail file so nothing is lost.
4. Content statements that are naturally a single assessable unit (e.g. a single named list explicitly presented as one bullet in the spec, like the eukaryotic organelle list in Biology §3.2.1.1) are kept as one ID rather than split purely to inflate the count — splitting only happens where the split reflects how the content is actually examined, not for its own sake.
5. Numbering within a section is sequential (001, 002, …) in the order the specification presents the content, so the ID order can be read alongside the spec itself.

This system is now fixed for the rest of the project. Batches 2–7 will extend it (Chemistry, Physics core + Astrophysics, Maths) without renumbering anything issued here.
